# Unraid Community Applications templates

Unraid templates for the apps I maintain. Community Applications reads this repository; the apps themselves live in their own repositories.

| App | Template | Project | Support |
| --- | --- | --- | --- |
| [Ledgerly](https://github.com/007darkmatter5/ledgerly) - personal finance: bills, running balances, loans | [`templates/ledgerly.xml`](templates/ledgerly.xml) | [ledgerly](https://github.com/007darkmatter5/ledgerly) | [Issues](https://github.com/007darkmatter5/ledgerly/issues) |
| [MeshVault](https://github.com/007darkmatter5/meshvault) - catalog for a 3D printing model collection | [`templates/meshvault.xml`](templates/meshvault.xml) | [meshvault](https://github.com/007darkmatter5/meshvault) | [Issues](https://github.com/007darkmatter5/meshvault/issues) |
| [Lansweeper Network Discovery](https://github.com/007darkmatter5/lansweeper-network-discovery) - unofficial container for the Lansweeper Hub and IT Sensor | [`templates/lansweeper-network-discovery.xml`](templates/lansweeper-network-discovery.xml) | [lansweeper-network-discovery](https://github.com/007darkmatter5/lansweeper-network-discovery) | [Issues](https://github.com/007darkmatter5/lansweeper-network-discovery/issues) |

Icons and screenshots are served from each app's own repository, so they stay in step with that app.

## Making a change

Edit the template here and push to `main`. Community Applications re-reads this repository on its own schedule, so no resubmission is needed.
